# T-916 — TDD evidence

**A guard against the next silent no-op.** Branch `m9-api-v1`, 2026-09-23.

T-915 fixed one decorative field. This is the test that would have caught it eight tasks earlier, and will catch the
next one. It was named in T-915's own gaps section as the thing still missing.

---

## 1. Why

`allowModelAccounts` survived T-906 through T-914 while being:

- declared on a public request record a caller posts to,
- described in a hand-authored OpenAPI document as *"let the model choose an account for a row no rule resolves"*,
- given a dedicated scope, `qb:post:ai`, that `scripts/new-api-client.ps1` will happily grant,
- and **read by no line of production code**.

Nothing in the suite objected, because nothing was looking. T-913's drift test compares the **routes** in
`openapi.json` against `EndpointDataSource`; it has no opinion about whether a documented *field* does anything. The
1346 tests passing at the end of M9 were all tests of behaviour that exists — and a no-op has no behaviour to test.

That is the gap: **the absence of an effect is invisible to a suite that only tests effects.**

## 2. RED — proving the guard catches the real case

## 3. What the guard asserts

| Test | Asserts |
|---|---|
| `Should_ReadEveryRequestField_When_ScanningProductionSources` | Every public property of `DirectRequest` and `DirectRow` is referenced in `src/**/*.cs` outside its declaring file. Reflection, not a hand-written list, so a field added tomorrow is covered without anybody remembering to add it. |
| `Should_UseEveryScope_When_ScanningProductionSources` | Every `ApiScopes` constant is referenced as `ApiScopes.<Name>` in production, unless reserved. |
| `Should_NameATrackerQuestion_ForEveryReservedScope` | Every reservation's reason contains a `Q-` reference. A reservation without a question is a no-op with paperwork. |
| `Should_NameARealScope_When_OneIsReserved` | Guards the guard: a typo in the reserved list would silently excuse a scope that does not exist while quietly ceasing to protect the one that does. |

`ApiScopes.QbPostAi` is the single reservation, citing Q-51 and Q-71. It is kept rather than deleted because the spec
lists it, and removing it would change the contract while Q-51 is open.

**The design point is not the token scan.** It is that adding a no-op now costs a deliberate, visible act: writing
your own name into `ReservedScopes` with a tracker question beside it. That is a thing a reviewer notices.

## 5. Known gaps — what this does **not** prove

1. **It is a token scan, not a compiler.** `sources.Contains("." + name)` cannot tell `DirectRow.Date` from any other
   type's `.Date`. Short, common property names — `Date`, `Amount`, `Account`, `Kind`, `Memo` — would pass this test
   even if nothing read them, because those tokens appear all over `src` for unrelated reasons. Doing it properly
   needs Roslyn, which is a package, which `CLAUDE.md` forbids without asking first.
2. **So the field test is strong exactly where it matters and weak elsewhere.** It catches distinctive new names —
   `allowModelAccounts` is unique in the tree — and that is the shape this defect actually took. It would not catch a
   no-op field called `Note`. Worth knowing before trusting it.
3. **The scope test is sound**, because `ApiScopes.` prefixes every reference; there is no collision to worry about.
4. **"Referenced" is not "enforced".** A scope named once in a comment, or a field read into a variable nothing uses,
   passes. This proves the surface is *touched*, never that it is *honoured*.
5. **Only two types are covered.** `DirectRequest` and `DirectRow` are checked because they are what a remote caller
   fills in. `CompanyFileRequest`, `ConnectionTestRequest`, `CreateJobRequest` and the settings classes are not. A
   decorative field on any of those is still invisible.
6. **Nothing checks the OpenAPI document against behaviour.** The original defect was as much a documentation lie as
   a code gap: `openapi.json` said the flag worked. T-913's drift test compares routes; nothing compares a
   description to what the code does, and nothing here changes that. It would need a person reading both.
7. **`new-api-client.ps1` still grants `qb:post:ai` without a word.** An operator can hand a caller a scope that
   confers nothing, and neither the script nor the server says so. Recorded, not fixed.
