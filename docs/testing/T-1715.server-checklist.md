# T-1715 server checklist: two approved companies end to end (acceptance A-11)

Tick each box on the QuickBooks server, in order. If a step does not match, stop, write what you saw next to it, and do
not go on. The agent could not run any of this: it needs the real QuickBooks, the two company files and the dashboard.
Never write a password or key into this file. Background: `docs/multi-company-m17.md` section 7 (A-9, A-11, A-12, A-13),
`docs/runbook.md` sections 2.5 and 8.3, ADR-0013. This also covers the items "Moved to T-1715" in
`docs/testing/T-1707.server-checklist.md`; do that checklist first, because item 9 here depends on its result.

**Safe on production data. Read before you start.**

- Take a recent QuickBooks backup of both company files first. Use COPIES of the company files if you can.
- Posting writes to QuickBooks. Post only **test statements with small amounts** (for example two or three lines of a few
  dollars, with a memo such as `T-1715 test`), made up for this checklist. **Never post a real statement twice**, and
  never post a real statement to prove a point. After each post, remove the test transactions with QuickBooks' own undo
  (the app's Undo, or delete them in QuickBooks, or restore the backup).
- The two sample PDFs (item 5) are only uploaded and read; do not validate or post them unless the file is a copy.
- Record times in seconds from the API log (`C:\qb-autopost\logs`).

Files used below: **T** = Takoma's `.qbw` (`18_Takoma Park Grocery Store Inc`), **S** = S & A's `.qbw`
(`440_S & A Convenience Market LLC`), **L** = the largest company file (T-1707 item 6).

- [ ] **7. Post with QuickBooks closed (both companies).** Close QuickBooks completely (no `QBW32.EXE` in Task Manager).

  Record: post time in seconds from the API log for T ____ and S ____, `QBW32.EXE` running in the background afterwards

- [ ] **10. Check access with another company open.** With T open in QuickBooks, press **Check access** for S. Record the
